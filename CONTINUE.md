# Netory — памятка для продолжения разработки

## Что передать другой ИИ

Лучше передать архив исходников, сохранив структуру:

```text
src/                         # вся папка целиком, включая pages и components
public/                      # статические файлы
package.json
pnpm-lock.yaml
index.html
vite.config.ts
tsconfig.json
.mise.toml
AGENTS.md
CONTINUE.md
.figma/make/site.json         # импортируется текущим vite.config.ts
```

Не передавать `node_modules/`, `dist/`, `.git/`, `.env*`, токены,
приватные ключи и временные логи. Новая ИИ установит зависимости из lockfile.
Полную папку `.figma` для работы над интерфейсом передавать не нужно.

## Стек и команды

- React 19, TypeScript, Vite 8, Tailwind CSS v4.
- Единственный глобальный CSS: `src/index.css`.
- Шрифт Manrope подключён через Google Fonts в CSS.
- Зависимости: `pnpm install --frozen-lockfile`.
- Проверка TypeScript: `pnpm exec tsc --noEmit`.
- Сборка: `pnpm run build`.
- Форматтер проекта: `pnpm run format`.
- В Figma Make сервер уже запущен: второй сервер не запускать.
- Вне Figma Make доступен `pnpm run dev`. В конфигурации есть Figma-специфичные
  плагины и импорт `.figma/make/site.json`; при переносе на другую платформу
  адаптировать их осознанно, не удалять вслепую.
- Хостинг должен отдавать `index.html` для маршрутов SPA.

## Карта кода

- `src/main.tsx` — вход, импорт CSS, React StrictMode.
- `src/App.tsx` — хедер, левое меню, лента, действия с постами,
  маршруты через History API, профильные настройки, видеокружки, футер.
- `src/components/HeaderMenus.tsx` — выпадающие уведомления и меню профиля.
- `src/pages/AuthPage.tsx` — регистрация и вход.
- `src/pages/SocialPages.tsx` — сообщения, друзья с фильтрами, раздел звонков
  и подключение страниц музыки и групп.
- `src/pages/MusicPage.tsx` — музыка: подборки, ambient-демо через Web Audio,
  локальные аудиофайлы, громкость, плеер.
- `src/pages/GroupsPage.tsx` — поиск сообществ, вступление, вкладка своих групп,
  раскрывающиеся темы.
- `src/pages/PostComments.tsx` — комментарии прямо под постом.
- `src/index.css` — все стили, адаптивность и анимации.
  Стили дорабатывались последовательно: нижние блоки переопределяют ранние.
  При будущей очистке CSS сохранить актуальный внешний вид и мобильные правила.

## Текущие маршруты

`/`, `/explore` («Обзор»), `/messages`, `/friends`, `/saved`, `/music`,
`/groups`, `/calls`, `/login`, `/register`, `/settings`, `/about`,
`/privacy`, `/notifications` (старый прямой маршрут), `/create`, `/circles`,
`/wave`, `/communities/design`, `/communities/travel`, `/communities/music`.
Основные переходы работают через History API, включая Назад/Вперёд.
Колокольчик открывает выпадающую панель, а не страницу уведомлений.

## Важные пожелания пользователя

- Русский интерфейс, основа белая, вторичные цвета чёрный и фиолетовый.
- Широкая соцсеть, не лендинг. Без вводных баннеров «ОТКРЫВАЙТЕ НОВОЕ»,
  больших названий раздела и рекламных описаний над содержимым.
- «Интересное» заменено на «Обзор». Тематические чипы Путешествия/Дизайн/
  Личное/Всё убраны. Фильтры друзей оставлены по предыдущему запросу.
- Хедер скруглённый, Лента / Обзор / Сообщения по центру,
  поиск раскрывается по кнопке, справа уведомления и аватар.
- Слева простые монохромные Музыка / Группы / Друзья / Звонки / Сохранённое.
- Настройки доступны из меню аватара. Служебные ссылки и копирайт слева убраны.
- Не повторять логотипы внутри страниц.
  Большое название в футере сохранено только у главной.
- Не добавлять поднятие карточек или кнопок на hover.
  Анимации действий с публикацией нужны, в том числе лайка и сохранения.
- Комментарии раскрываются под публикацией, не модальным окном.
- В сообщениях нужен выбор получателя; на мобильном список и чат
  переключаются кнопкой «Назад».
- Регистрация, вход и остальные разделы имеют отдельные адреса.
- Фотографии загружаются с Unsplash, аватары — с pravatar.cc.
- Для конкретных Figma-референсов пользователь пока не дал ссылок:
  не утверждать, что они просмотрены. Попросить URL нужных фреймов при
  необходимости точного воспроизведения.

## Что реально работает, а что демонстрационное

- Нет backend, базы данных, реальной авторизации или обмена сообщениями
  между пользователями. Формы валидируются браузером, вход меняет UI-состояние.
- Посты, реакции, подписки, комментарии и вступления — локальное состояние
  компонентов; могут сбрасываться при обновлении или переходе.
- Сообщения — локальные исходящие, раздельно по собеседникам,
  хранятся в `sessionStorage` под ключом `netory-threads`.
- Черновики сообщений — память компонента, без серверного хранения.
- Кружок записывается камерой через MediaRecorder с разрешения пользователя;
  нет загрузки на сервер или отправки получателю.
- Звонки между пользователями не подключены, раздел явно обозначен как демо.
- Музыкальные ambient-демо — синтезированные аккорды в браузере;
  локальные аудиофайлы воспроизводятся без отправки на сервер.
- Уведомления, профили и темы групп — демонстрационные данные.
- Нет полноценного backend-поиска и алгоритма подбора «На одной волне».

## Проверки

После последних изменений успешно выполнены TypeScript и production build.
Браузерная визуальная проверка в текущей среде не выполнена:
инструмент просмотра работающего веб-приложения не был доступен.
При продолжении проверить реальные desktop/mobile экраны, выпадающие панели,
аудио, разрешения камеры и клавиатурную навигацию.
